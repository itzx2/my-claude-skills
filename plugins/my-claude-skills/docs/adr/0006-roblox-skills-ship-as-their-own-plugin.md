# 0006. The Roblox skills ship as their own plugin

Date: 2026-10-26

## Status

Accepted. Ships as `my-claude-skills` 3.0.0 and `my-roblox-skills` 1.0.0.

## Context

Since 2.3.2 the 29 Roblox Brain skills shipped inside `my-claude-skills`, which
made 75 skills in one plugin. Only Roblox projects need them, yet every session
everywhere listed all 29 in its Skill listing, and `ask-matt` carried a separate
Roblox routing reference.

The user asked for the Roblox skills to be separated from the rest, kept in this
repository, with a Roblox router of their own and a briefing every agent gets.

## Decision

The Roblox skills move to a third plugin in this marketplace,
**`my-roblox-skills`**, at `plugins/my-roblox-skills/`. That folder is
hand-maintained, like `plugins/savvy-progress/`, rather than generated by
`scripts/marketplace-payload.js`.

- **One repository, one marketplace, three plugins.** Claude Code reads one
  `.claude-plugin/marketplace.json` from a repository root, so two marketplaces
  would mean two repositories. Separate plugins give the same thing that
  matters: each one installs, updates and is switched off on its own.
- **The skills stay verbatim.** The vendor record gives each one a `dest` under
  the new plugin, so `vendor.js take` and `check` work unchanged.
- **The plugin stands alone.** It needs nothing from `my-claude-skills` and
  ships its own router (`ask-roblox`, user-invoked like `ask-matt`) and its own
  briefing hook. `ask-matt` hands Roblox requests to `ask-roblox` when the
  plugin is installed.
- **The briefing runs at SessionStart and SubagentStart.** A subagent never
  sees the main session's start-up context, and Roblox work is often
  delegated. It sends the full route only in a folder that looks like a Roblox
  project, and a short pointer elsewhere, because Studio MCP work can happen
  with no repository open (the user chose this over always-full and
  project-only).
- **The plugin is named `my-roblox-skills`**, the user's choice, which matches
  `my-claude-skills` and avoids clashing with upstream's `roblox-brain`.
- **Each plugin carries the licenses of what it copies.** An install copies
  only the plugin's folder, so the MIT notices for roblox-brain and claude-kit
  sit inside their plugins, and the other upstreams' notices sit in
  `vendor/licenses/`, which the main payload includes.

## Consequences

- **Breaking for existing users:** `my-claude-skills:roblox-*` stops resolving.
  It becomes `my-roblox-skills:roblox-*`, after installing the new plugin. That
  is why the main plugin goes to 3.0.0.
- Any change under `plugins/my-roblox-skills/` bumps its own version in its
  `plugin.json` and its `marketplace.json` entry, the same rule as the other
  two plugins.
- A non-Roblox session costs the pointer, about 450 characters, instead of 29
  extra Skill listing entries.
